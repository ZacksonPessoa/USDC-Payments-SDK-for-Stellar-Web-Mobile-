# 📘 Internal Documentation — USDC Payments SDK for Stellar

This `/docs` directory contains all **internal design and architecture documents** for the project.

---

## 📄 Files Included

### 1. `Stellar_Payments_SDK_Scaffold.pdf`
- Full technical scaffold of the SDK repository.  
- Describes folder structure, build setup, CI, example apps, and next steps for Phase 1.  
- Serves as a **blueprint** for developers joining the project.

### 2. `stellar_payments_sdk_architecture.svg`
- Visual architecture diagram used in the SCF submission.  
- Illustrates integration between Merchant App → SDK → Stellar Horizon → On/Off-Ramp.

### 3. `SCF.md`
- Full Stellar Community Fund submission file (problem, solution, impact, roadmap, KPIs, etc).  
- Should remain in the root, but a copy may be referenced here for documentation completeness.

---

## 🧩 Purpose
This folder ensures the team can **rebuild, understand, or extend** the SDK with full technical and architectural context.  
It centralizes **developer onboarding materials** and **project specifications**.

---

## 🧭 Recommended Folder Structure

```
/docs
 ├─ Stellar_Payments_SDK_Scaffold.pdf
 ├─ stellar_payments_sdk_architecture.svg
 ├─ README.md (this file)
```

## 💡 How to Use
- **Developers:** Review the PDF before editing the core SDK structure.  
- **Contributors:** Reference the diagram for architectural decisions.  
- **Grant reviewers (SCF):** Use the SCF.md + diagram for project overview.
